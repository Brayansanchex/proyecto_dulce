  BUSCAR PRODUCTOS : Use Case

Permite al cliente localizar productos utilizando el nombre del postre o la categoría a la que pertenece.

  REGISTRAR : Use Case

Permite al cliente crear una cuenta proporcionando nombres, apellidos, número telefónico, correo electrónico y dirección para envíos.

  INICIAR SESION : Use Case

Permite al usuario ingresar sus credenciales para acceder al sistema y determinar el rol correspondiente, ya sea cliente o administrador.

  CONSULTAR CATALOGO : Use Case

Permite al cliente visualizar los postres disponibles junto con su imagen, descripción y precio.

  PERSONALIZAR PRODUCTO : Use Case

Permite al cliente seleccionar las características disponibles de un producto, como sabor, toppings, tamaño, mensaje especial, relleno y decoraciones.

  ADMINISTRAR CARRITO DE COMPRAS : Use Case

Permite al cliente agregar productos al carrito y modificar los productos que contiene antes de realizar el pedido.

  REALIZAR PEDIDO : Use Case

Es necesario para que el cliente pueda preparar y modificar su compra antes de confirmarla.

  REGISTRAR CUMPLEAÑOS : Use Case

Permite al cliente registrar su nombre, correo electrónico, fecha de nacimiento y documento de identidad relacionados con su cumpleaños y se administra para las promociones especiales.

  CONSULTAR PEDIDOS : Use Case

Permite al cliente consultar sus pedidos realizados y aquellos que actualmente se encuentran en proceso. También permite filtrar los pedidos por fecha.

  ADMINISTRAR DIRECCIONES : Use Case

Permite al cliente consultar las direcciones utilizadas y agregar o modificar direcciones para los envíos.

  CONSULTAR OFERTAS : Use Case

Permite al cliente visualizar las ofertas exclusivas disponibles para usuarios que hayan iniciado sesión.

  FILTRAR PEDIDOS : Use Case

Permite al administrador filtrar pedidos por estado, fecha desde y fecha hasta.

  BUSCAR PEDIDO : Use Case

Permite al administrador localizar un pedido utilizando los filtros disponibles.

  CAMBIAR ESTADO DEL PEDIDO : Use Case

Permite al administrador establecer o actualizar el estado de un pedido entre Pendiente, En proceso, Enviado y Entregado.

  AGREGAR PRODUCTO : Use Case

Permite al administrador incorporar nuevos productos al catálogo del sistema.

  EDITAR PRODUCTO : Use Case

Permite al administrador modificar la información de un producto existente.

  MODIFICAR ESTADO : Use Case

Permite al administrador modificar el estado de disponibilidad de un producto.

  ADMINISTRAR CLIENTES : Use Case

Permite al administrador consultar información de los clientes, incluyendo nombre, correo electrónico, número de pedidos y total gastado.

  ADMINISTRAR CODIGOS PROMOCIONALES : Use Case

Permite al administrador modificar el estado de los códigos promocionales, activándolos o desactivándolos.

  CONSULTAR ENVIOS : Use Case

Permite al administrador visualizar las estadísticas relacionadas con los envíos de los productos.

  CONSULTAR VENTAS : Use Case

Permite al administrador identificar cuál es el producto que registra mayores ventas.
