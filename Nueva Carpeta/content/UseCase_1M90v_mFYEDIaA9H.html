Description

Use Case Note
■ Workflow
    • Cliente accede al historial.
    • Sistema consulta sus pedidos.
    • Cliente puede aplicar un filtro por fecha.
    • Sistema muestra los resultados.
    •
■ Business Logic
    • El cliente solo debe consultar sus propios pedidos.
    • Deben mostrarse pedidos realizados y pedidos en proceso.
    • Se debe permitir filtrar por fecha.
    •
■ Decisions
    • ¿El cliente desea filtrar por fecha?
    • ¿Existen pedidos para el período seleccionado?
    •
■ Follow-up
    • El cliente puede consultar otro período.
    • El cliente puede revisar nuevamente sus pedidos.
    •

Scenario
Steps
1. El cliente inicia sesión.
2. El sistema valida las credenciales del cliente.
3. El sistema muestra el menú principal.
4. El cliente selecciona la opción “Consultar pedidos”.
5. El sistema consulta los pedidos asociados al cliente.
6. El sistema muestra la lista de pedidos realizados por el cliente.
7. El cliente selecciona un pedido para consultar su información.
8. El sistema muestra los detalles del pedido seleccionado.
9. El cliente puede regresar a la lista de pedidos o finalizar la consulta.
