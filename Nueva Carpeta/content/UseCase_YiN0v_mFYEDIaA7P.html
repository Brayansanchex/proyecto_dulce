Use Case Note
■ Workflow
    • El cliente accede al formulario de registro.
    • Ingresa sus datos personales y de contacto.
    • Envía la información.
    • El sistema valida y registra la cuenta.
    •
■ Business Logic
    • El sistema debe solicitar los datos definidos para el registro.
    • El correo electrónico identifica al usuario y no debe existir otro registro con el mismo correo.
    • La cuenta debe quedar registrada para permitir posteriormente el inicio de sesión.
    •
■ Decisions
    • ¿Los datos requeridos fueron proporcionados?
    • ¿El correo electrónico ya está registrado?
    •
■ Follow-up
    • El cliente puede iniciar sesión con la cuenta registrada.
    • El cliente puede utilizar las funcionalidades disponibles para usuarios registrados.
    •

Scenario 1 — Registro exitoso
Steps
1. El cliente selecciona la opción "Registrarse".
2. El sistema muestra el formulario de registro.
3. El cliente ingresa sus nombres.
4. El cliente ingresa sus apellidos.
5. El cliente ingresa su número telefónico.
6. El cliente ingresa su correo electrónico.
7. El cliente ingresa su dirección.
8. el cliente ingresa su fecha de cumpleaños
9. El cliente selecciona la opción para enviar el formulario.
10. El sistema recibe la información proporcionada por el cliente.
11. El sistema registra la información del cliente.
12. El sistema confirma que el registro se realizó correctamente.
