Description

La entidad Clientes almacena la información personal, de identificación y contacto de las personas que se registran en la plataforma web de Dulce Capricho. Permite identificar a los usuarios que realizan pedidos y utilizan los servicios ofrecidos por el sistema.

Primary Key Clustered Unspecified
Unlogged false
Temporal false

Columns Summary
Column Name Data Type PK / FK Nullable Description
id_cliente integer(10) PK No

Identificador único asignado a cada cliente registrado en el sistema.

Nombre varchar(50) No
Apellido varchar(50) No

Nombre del cliente que realiza el registro en la plataforma.

id_documento integer(10) FK No

Identificador del tipo de documento de identidad del cliente. Se utiliza para relacionarlo con la entidad Tipo de Documento.

Numero Documento varchar(25) No

Número correspondiente al documento de identificación del cliente.

Fecha de Nacimiento date(0) No

Fecha de nacimiento registrada por el cliente.

Telefono varchar(20) No

Número telefónico utilizado como medio de contacto con el cliente.

id_correo integer(10) FK No

Identificador relacionado con la información de correo electrónico del cliente.

id_ciudad integer(10) FK No

Identificador de la ciudad donde reside el cliente. Se relaciona con Ciudad.

Dirección varchar(150) No

Dirección registrada por el cliente para facilitar la información relacionada con sus pedidos.
